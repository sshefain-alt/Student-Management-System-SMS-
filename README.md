# Student-Management-System-SMS-
🎓 Bilingual (Bangla + English), mobile-first School Management System (SMS) for Bangladesh schools. Features 5 distinct RBAC role dashboards, NCTB GPA 5.0 grading, &lt;1-min attendance with carrier SMS alerts, bKash fee ledger with advance/due tracking, and full SE course documentation.
